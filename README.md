# Hollow Faith — Forge 1.20.1 (хоррор + вымышленный культ Пустого Бога)

⚠ Мод содержит скримеры: резкие громкие звуки, вспышки, тряску камеры и пугающие картинки.

## Сборка (Java 17)
    gradle wrapper --gradle-version 8.1.1    # один раз
    ./gradlew build                           # jar -> build/libs/hollowfaith-1.0.0.jar
    ./gradlew runClient                       # тестовый запуск
Нужен Forge 47.2.0+ для Minecraft 1.20.1. Мод нужен и на клиенте, и на сервере.

## Скримеры
- Культист подошёл вплотную / ударил (шанс 25%) -> скример
- Эффект «Ужас» -> случайный скример (не чаще раза в 30 с), звуки за спиной, шёпот
- Алтарь: «гнев» великого ритуала и неудачный малый ритуал -> скример
- Команда для теста: /hollowfaith scare [0|1]  (нужны права оператора)

## Настройки: config/hollowfaith-client.toml
jumpscares (вкл/выкл), flashes (вспышки), cameraShake (тряска), soundLayers (1-4, громкость)

## Громкость
Minecraft ограничивает громкость одного звука 100%, поэтому «громче» сделано
наложением нескольких звуков (soundLayers) в категории MASTER — ползунки категорий на них не влияют.
